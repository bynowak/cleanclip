# Store listing copy

**Name:** CleanClip — Copy with clarity

**Short description:** Clean copied text locally. Keep paragraphs, headings, lists and tables as plain text, Markdown or safe rich text.

**Suggested category:** Productivity / workflow tools. Final category depends on the store's current taxonomy.

## Description

Copy the content. Keep the structure.

CleanClip removes formatting clutter from copied website text while preserving the parts that make it useful: paragraphs, headings, lists, tables, links and code.

Choose plain text for readable notes, Markdown for documentation, or cleaned rich text for an editor. Preview the input and result before copying, or opt in to automatic cleaning for ordinary website copies.

Four presets help you get started:

- Plain: readable text without website styling.
- Markdown: headings, lists, clean links, tables and code.
- Writing: straight quotes and link labels for your drafts.
- Developer: Markdown with code-sensitive whitespace and Unicode preserved.

Customize tracking-parameter removal, invisible-character cleanup, whitespace normalization, paragraphs, headings, lists, link destinations, smart quotes and recognizable chat citation artifacts.

Local by design: no analytics, no telemetry, no network calls, no clipboard history, and no account. Only your preferences are stored on your device. Automatic cleaning is off by default and asks for website access when enabled. One-off selection cleaning uses temporary active-tab access.

Keyboard commands are configurable in your browser. Restricted browser pages and some custom editors require pasting into the preview. Basic tables are supported; merged cells are flattened with a warning. The extension does not retain fonts, colors, scripts or remote images.
