# Changelog

All notable changes are recorded here. Versions follow semantic versioning.

## 1.0.0 — 2026-10-04

- Added independent HTML/text transformation core with plain, Markdown and safe rich output.
- Added tracking URL cleanup, Unicode/prose controls, nested lists, basic tables and code preservation.
- Added Plain, Markdown, Writing and Developer presets with custom settings.
- Added local-only popup previews, copy confirmations and settings without clipboard history.
- Added opt-in automatic cleaning, active-tab selection copying and keyboard command support.
- Added fixtures, permission boundary tests, unpacked Chrome/Chromium acceptance, packaging and CI.
- Prepared Chrome Web Store and Edge Add-ons listings, privacy disclosure and image assets. Store submissions remain pending publisher registration/review.
