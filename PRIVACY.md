# CleanClip privacy policy

Effective date: October 4, 2026. Publisher: Mateusz Nowak (By Nowak).

CleanClip cleans text locally in your browser. It does not collect, transmit, sell or share personal data. It contains no analytics, advertising, telemetry, external API calls, remote code or remotely hosted assets.

## What is processed

When you choose a one-off copy, paste content into the preview, or enable automatic cleaning and copy a website selection, CleanClip processes that text and the associated selected HTML in memory. This processing provides the extension's single purpose: clean copied text. It does not continuously scan page content or poll your system clipboard.

The source page address may be used locally to resolve relative links. It is not logged, transmitted or retained. The extension does not request permission to read your system clipboard. Paste events provide the text you explicitly paste, and copy actions write the result you requested.

## What is stored

Only preferences (selected preset, cleaning toggles, automatic-cleaning state and confirmation preference) are stored in browser extension local storage. They are not synced. The preview draft is transient and is cleared when that UI closes or reloads. There is no clipboard history, account system or server-side storage.

Requested output is written to the operating system clipboard. Your browser, operating system, other extensions and receiving applications may independently handle clipboard data; their behavior is not controlled by CleanClip.

## Website access

One-off selection cleaning uses temporary active-tab access after you invoke the extension. Automatic cleaning is off by default. Enabling it asks for HTTP/HTTPS website access so CleanClip can handle your copy events. You can disable automatic cleaning in the popup or settings page and revoke website access in settings. Uninstalling CleanClip removes its preferences according to your browser's normal extension lifecycle.

## Support and policy updates

For privacy questions contact business@bynowak.com. Information you voluntarily include in an email or GitHub issue is handled by that service; do not attach private clipboard content. This policy will be updated before any material change to data handling. A change requiring remote processing would require a separate product decision and disclosure; v1 performs no remote processing.
